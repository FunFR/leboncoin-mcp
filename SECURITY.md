# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not report a vulnerability in a public issue. Report it privately through GitHub instead: on the [Security tab](https://github.com/FunFR/leboncoin-mcp/security) of this repository, select **Report a vulnerability**. Only you and the maintainer can see the report.

This server is maintained in spare time, so fixes are made on a best-effort basis.

Vulnerabilities in Leboncoin itself are outside this project: please report them to Leboncoin.
